# Calculadora en Python con Tkinter

# 1. Descripción
Este proyecto consiste en realizar una calculadora usando Python y la herramienta Tkinter. La calculadora permite realizar operaciones matemáticas básicas de una manera sencilla.

# 2. Objetivo
Crear una calculadora que permita sumar, restar, multiplicar y dividir dos números ingresados por el usuario.

# 3. Herramientas utilizadas
- Python
- Tkinter
- Visual Studio Code

## 4. Funciones de la calculadora
- Sumar: suma dos números.
- Restar: resta el segundo número al primero.
- Multiplicar: multiplica dos números.
- Dividir: divide el primer número entre el segundo. Si el segundo número es cero, muestra un mensaje de error.

# 5. Funcionamiento
El programa tiene una ventana donde el usuario puede escribir dos números. Después, puede seleccionar uno de los cuatro botones para realizar la operación. El resultado aparece en una casilla dentro de la misma ventana.

# 6. Conclusión
Con este proyecto aprendí a utilizar algunas herramientas de Tkinter para crear ventanas, casillas de texto y botones. También practiqué el uso de variables, funciones, condicionales y operaciones matemáticas en Python.
