Calculadora en Python con Tkinter

Descripción

Este proyecto consiste en una calculadora gráfica desarrollada en Python utilizando la librería Tkinter. Permite realizar operaciones matemáticas básicas mediante una interfaz con botones.

Funcionalidades

* Sumar varios números en una misma operación.
* Restar varios números en una misma operación.
* Multiplicar varios números en una misma operación.
* Dividir varios números en una misma operación.
* Botón C para limpiar toda la pantalla.
* Botón D para eliminar el último carácter escrito.
* Botón = para mostrar el resultado.
* Manejo de errores al intentar dividir por cero.
* Reinicio de la pantalla cuando aparece un error.


Ejemplos de uso

Operación	Resultado
* 5 + 3 + 2	= 10
* 2 * 3 * 4	= 24
* 20 - 5 - 3	= 12
* 100 / 2 / 5	= 10


Interfaz

La calculadora cuenta con una pantalla para mostrar los números y resultados, y una matriz de botones para ingresar números y seleccionar las operaciones.
